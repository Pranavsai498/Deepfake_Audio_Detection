Synthetic Voices Dataset — 500 WAV clips
========================================
Generated offline using the locally installed eSpeak speech synthesizer.
This is a basic synthetic-speech pipeline dataset, NOT a realistic neural TTS or voice-cloning benchmark.
It is not generated by FreeVC24, VITS, XTTS, or ChatGPT voice. eSpeak voices can sound robotic, and
Telugu is the installed 'telugu-test' voice. English uses generic eSpeak English, not verified Indian English.
All WAV files are mono PCM at 16 kHz. Telephone-condition files use a 300–3400 Hz bandpass filter.
metadata.csv includes file_name, language, scenario, condition, sample rate, duration, engine, label, and text.
Do not use this dataset alone to claim robustness to modern neural voice deepfakes.
